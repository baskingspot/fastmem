## Decision (main, `-Dx86-experiment=auto`)

- c8i: medium-entry. 65-256 B reaches parity (copy 1.01, move 1.01, set
  1.00). The 0-64 B fixed rows cost 0.2-0.3, but the size distributions do
  not regress (copy dist/small 0.44 to 0.47, set 0.63 to 0.57, move
  dist/small 0.91 to 0.84).
- c7i: small-paths' short-first inline dispatch. Inline copy 0-16 B 1.18 to
  0.53, move 1.05 to 0.70. The predicted 32-256 B cost did not appear.
- c7a: unchanged. The Zen 4 short classes improve 0-16 B slightly and lose
  at 17-256 B.
- The composite's `.text` is byte-identical per model to the measured
  binaries (graniterapids = v2, sapphirerapids = v3, znver4 and znver5 =
  v0), so these numbers and the hardware correctness runs apply to it
  unchanged.

Open: c8i 0-64 B fixed rows after medium-entry (copy 0-16 1.13, 17-64 1.20);
c7a 0-16 B against compiler-rt (1.33, a constant 0.54 ns not explained by
instruction counts).
